# Windows 功能拓展

本轮功能在 `codex/amberol-glass-features` 分支实现，保留 Amberol 的本地播放方式和专辑封面取色。

## 透明与磨砂背景

“外观与窗口 → 磨砂背景”控制背景效果。支持的 Windows 11 使用 DWM 系统 Acrylic 背景，专辑配色以半透明渐变叠加其上；文字、封面、按钮和波形独立绘制，不降低整个窗口的不透明度。

原生接口要求 Windows 11 build 22621 或更新版本，见 [Microsoft 的系统背景接口说明](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)。接口不可用时保留实色背景和界面内的半透明卡片。高对比度模式关闭磨砂及封面背景取色。系统透明设置、主题和显卡渲染会影响实际表现。

## 使用方式

| 功能 | 入口或快捷键 | 行为 |
|---|---|---|
| 迷你播放器 | 外观与窗口；Ctrl+M | 缩小窗口、封面和曲目信息，收起列表、音量条及歌词；再次切换返回完整窗口 |
| 窗口置顶 | 外观与窗口；Ctrl+T | 切换 Windows 原生置顶状态 |
| 本地歌词 | 外观与窗口；Ctrl+Y | 读取同目录、同文件名的 UTF-8 `.lrc`，显示当前行和下一行 |
| 歌词偏移 | 歌词面板 | 正值提前，负值延后；支持 ±10 秒，以 100 毫秒调整；切歌后重置 |
| 收藏 | 歌单与收藏；Ctrl+D | 收藏或取消收藏当前歌曲；“打开收藏”将收藏歌曲加入队列 |
| 命名歌单 | 歌单与收藏 | 保存当前队列；打开时追加到队列；同名歌单不覆盖 |
| M3U 导入导出 | 歌单与收藏 | UTF-8 M3U / M3U8，支持相对路径及文件 URI；直接打开或拖入歌单也可导入 |
| 最近文件夹 | 主菜单 | 记录最近 8 个添加过的目录；再次打开时扫描并追加歌曲 |
| 状态恢复 | 播放设置 | 保存队列、歌曲、秒级进度、音量、循环模式及确切随机顺序；启动时恢复 |
| 恢复后自动播放 | 播放设置 | 默认关闭，恢复后暂停；打开选项后恢复并播放 |
| 播放 / 暂停淡化 | 播放设置 | 约 180 毫秒的渐变；切歌后保留用户音量 |
| 睡眠定时 | 主菜单 | 30、60、90 分钟后暂停；可取消；退出后不保留定时 |
| A–B 循环 | 主菜单 | 在当前进度标记 A，再在更晚处标记 B；循环该区间，切歌时清除 |

歌词支持毫秒、同一行多个时间标签和 `[offset:]` 标签。播放位置每 250 毫秒更新一次。第一版使用本地歌词，不自动下载歌词。

开启后台播放时，关闭窗口会隐藏到系统托盘。托盘左键打开窗口，右键控制播放、切歌或退出。若托盘创建失败，关闭窗口仍正常退出。

## 播放和持久化

音频后端使用 GStreamer playbin，通过 `about-to-finish` 提前设置下一首，在流开始时同步队列、封面、歌词和系统媒体信息，接口行为见 [GStreamer playbin 文档](https://gstreamer.freedesktop.org/documentation/playback/playbin.html)。连续切歌不主动停止管线再播放。实际连续性仍取决于音频格式、编码延迟和输出设备。

当前淡化用于播放、暂停及新曲目的淡入。两首歌重叠混音的交叉淡化没有实现，需要独立混音管线及额外状态协调。

播放状态和歌单位于 GLib 用户数据目录的 `amberol/` 下。状态每 10 秒保存，关闭及正常退出也保存；收藏和歌单独立于临时缓存。JSON 与歌单采用临时文件写入后替换。缺失文件会跳过，失效的随机索引不会强行应用。

## 验证范围

已执行 Windows release 构建和便携包生成。测试覆盖真实 GStreamer 管线上的连续切歌、循环、暂停淡化、音量保持、进度恢复、随机顺序及删除后的当前曲目；另覆盖中文 M3U 路径、非法歌单名称及 LRC 解析。

界面检查使用独立数据目录、静音 WAV 和测试封面，检查磨砂背景、完整窗口、迷你模式、歌词面板和菜单布局。旧 Windows 的降级路径未在对应系统实机验证，音频格式、DPI 和显卡组合未逐一验证。

程序位于 `dist/amberol-windows-portable/Amberol.exe`，压缩包位于 `dist/amberol-windows-portable.zip`。构建目录、便携包和测试配置不纳入 Git。
